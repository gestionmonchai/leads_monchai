Exporter vos données

Ce que vous pouvez récupérer de Mon Chai, depuis quelle page et en quel format.

Pour récupérer des données dans votre application, deux voies existent : l'API REST v1 ou le connecteur, pour des réponses ciblées et à jour (stocks, factures), et les exports ci-dessous, pour des fichiers complets. Les exports se téléchargent depuis l'interface de Mon Chai, par une personne connectée qui a le droit de voir ces données ; il n'existe pas d'export par programme.

Format des fichiers CSV : UTF-8 (presque toujours avec BOM, pour qu'Excel affiche les accents), séparateur point-virgule, une ligne d'en-tête. Une cellule qui commencerait par =, + ou @ est précédée d'une apostrophe, pour qu'aucun tableur ne l'exécute comme une formule : retirez-la si votre application relit la valeur brute. Les fichiers destinés à l'interprofession suivent le format qu'elle impose.

L'aller-retour avec les imports

Pour les types importables, l'export « au format du modèle d'import » rend vos données existantes avec exactement les colonnes de la page Importer vos données : votre application peut le lire, le corriger, puis le rendre à Mon Chai par un import, qui mettra à jour les éléments existants grâce à leur clé.
