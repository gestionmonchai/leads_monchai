## Mesurer (à faire une fois, puis mensuel)

1. **Google Search Console** : ajouter la propriété `monchai.fr` (validation
   DNS chez le registrar), soumettre `https://monchai.fr/sitemap.xml`.
   Sans ça, aucune donnée de positionnement.
2. **Chaque mois** : dans Search Console → Performances, filtrer les pages
   `/actualites` et les articles ; noter impressions, clics, position
   moyenne par mot-clé principal. Reporter ici les positions dans une
   colonne datée.
3. **Ajuster** : un article qui sort en position 15-30 sur son mot-clé
   mérite un enrichissement (section FAQ, exemples chiffrés, mise à jour de
   dates) plutôt qu'un nouvel article sur le même sujet.

## Veille tendances (protocole pour les prochains articles)

À chaque session de production d'articles (idéalement mensuelle) :
- Passer en revue : actualités DGDDI (douane.gouv.fr), agriculture.gouv.fr,
  DGCCRF, chambres d'agriculture, Vitisphere / Réussir Vigne / La Vigne.
- Chercher les échéances à 2-4 mois (les lecteurs cherchent AVANT la date).
- Croiser avec Search Console : les requêtes en croissance où monchai.fr
  apparaît déjà loin sont les meilleurs sujets suivants.
- Ajouter les nouveaux articles en file avec `prevu` hebdomadaire, en
  respectant LIGNE-EDITORIALE.md.
