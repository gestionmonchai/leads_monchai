Importer vos données

Les fichiers CSV que Mon Chai sait importer : colonnes, formats, limites et modèles à télécharger.

Pour envoyer des données à Mon Chai, votre application produit un fichier CSV ; une personne de l'exploitation le dépose dans Référentiels › Importer des données (ou dans Mes données, qui reconnaît le type du fichier). Mon Chai lit tout le fichier, montre ce qu'il va créer et modifier, et n'écrit rien avant la confirmation. Il n'existe pas d'import par programme.

Les colonnes, formats et modèles ci-dessous sont engendrés depuis le moteur d'import de Mon Chai : ce sont exactement ceux qu'il accepte. L'import peut être réservé à certains rôles et le module fermé pour une exploitation : dans ce cas, l'écran d'import le dit.

Le format commun à tous les fichiers

  • Extension .csv uniquement (pas d'Excel, de PDF ni d'archive, quel que soit le nom du fichier).
  • Encodage UTF-8, avec ou sans BOM ; séparateur ; (point-virgule) ; guillemet " pour une cellule qui contient un point-virgule ou un retour à la ligne.
  • Première ligne : les noms de colonnes ci-dessous, non vides et sans doublon ; l'ordre est libre, les colonnes facultatives peuvent manquer. Mon Chai propose une correspondance pour les noms proches (« alias »), que la personne confirme.
  • Dates AAAA-MM-JJ ; nombres décimaux avec un point (2.50) ; vrai/faux : true ou false ; espaces en début et fin de cellule ignorés ; lignes entièrement vides ignorées.
  • Limites : 2048 Ko, 1000 lignes de données, 30 colonnes, 300 caractères par cellule.

« Mes données » accepte aussi les fichiers tels qu'Excel ou Google Sheets les enregistrent : encodages UTF-8, Windows-1252 (Excel), Mac OS Roman (ancien Excel sur Mac) ; séparateurs « ; » (point-virgule), « ⇥ » (tabulation), « , » (virgule), « | » (barre verticale). La lecture détectée est affichée et doit être confirmée ; le fichier est ensuite converti au format commun. Votre application a tout intérêt à produire directement de l'UTF-8 avec des points-virgules.

Créer ou mettre à jour

Chaque type a une clé de rapprochement (colonnes marquées « clé ») : une ligne dont la clé désigne un élément existant le met à jour, sinon elle en crée un. Une cellule vide ne modifie rien. Les colonnes « obligatoire » le sont à la création. Les identifiants internes de Mon Chai ne s'importent jamais.

Fichier refusé : les raisons possibles

Extension autre que .csv ; contenu binaire (tableur, PDF, image) ; encodage autre que UTF-8 ; fichier vide ou sans ligne de données ; séparateur autre que le point-virgule ; en-tête vide ou en double ; trop de lignes, de colonnes ou de caractères. Une ligne invalide est signalée avec son numéro et la correction à faire, dans un rapport téléchargeable ; les autres lignes ne sont écrites qu'après votre confirmation.

Cépages Référentiels

Constituer la liste des cépages de votre exploitation, utilisée par l'encépagement des parcelles et les lots de chai.

Clé de rapprochement : le code FAM/Douanes (colonne « code ») s'il est renseigné, sinon le nom normalisé (unique dans votre organisation).

Code officiel court ; sert de clé s'il est renseigné.
Alias reconnus : code_officiel, ref, reference, référence		 Texte — 10 caractères au plus 08
couleur Couleur de la peau
Alias reconnus : color		 Valeur imposée
Valeurs : noir, rouge, blanc, gris, rose, teinturier		 blanc
notes Notes
Alias reconnus : commentaire, commentaires, comments		 Texte long Sélection massale

À créer avant : Aucune. Pour les cépages officiels, préférez le choix depuis le catalogue interne (Référentiels > Cépages), plus complet.

Ne s'importe pas : Les fiches détaillées du catalogue national (phénologie, sensibilités, aptitudes) : elles proviennent du référentiel officiel.

Modèle (version v1) : télécharger modele_import_cepage_v1.csv

nom;code;couleur;notes
Chenin;08;blanc;
Erreurs fréquentes
  • « Couleur invalide » : Utilisez l'une des valeurs autorisées : noir, rouge, blanc, gris, rose ou teinturier.
  • « Le code désigne un autre cépage » : Le code et le nom de la ligne pointent deux fiches différentes : corrigez l'un des deux.

  • « Adresse incomplète » : Dès qu'une colonne d'adresse est renseignée, la rue, le code postal et la ville deviennent obligatoires.

Lignes de grille tarifaire Tarifs

Alimenter UNE grille tarifaire : prix par produit, avec un seuil de quantité facultatif et une remise facultative.

Avant le dépôt, la personne choisit la grille tarifaire visée : le fichier ne porte que les lignes.

La grille est choisie avant le dépôt du fichier : elle ne figure jamais dans le CSV. Une ligne est identifiée par le produit et le seuil de quantité minimale (vide = tarif de base).

ColonneContenuFormatExemple
reference_produit obligatoire clé Référence article
Référence d'un produit existant.
Alias reconnus : sku, code_sku, reference, ref_produit		 Nom d'un élément existant — 64 caractères au plus VOU-BLC-75
quantite_min clé Quantité minimale
Laisser vide pour le tarif de base.
Alias reconnus : qte_min, min_qty, seuil		 Nombre entier — au moins 1, au plus 1000000, sans décimale (1200) 6
prix_unitaire obligatoire Prix unitaire HT (€)
Alias reconnus : prix, unit_price, prix_ht		 Nombre décimal — au moins 0.01, au plus 99999999, point décimal (2.50) 8.50
remise_pct Remise (%)
Alias reconnus : remise, discount_pct		 Nombre décimal — au moins 0, au plus 100, point décimal (2.50) 0

À créer avant : Le produit doit exister dans votre catalogue et porter une référence article : l'import ne crée jamais de produit. La grille tarifaire doit exister : sélectionnez-la avant le dépôt.

Ne s'importe pas : La devise et les dates de validité : elles appartiennent à la grille, pas à la ligne. Aucune suppression : les lignes absentes du fichier restent en place. Il n'existe pas de mode « remplacer la grille ».

Modèle (version v1) : télécharger modele_import_tarif_v1.csv

Erreurs fréquentes
  • « Produit introuvable » : Vérifiez la référence article, ou importez d'abord vos produits.
  • « Prix invalide » : Le prix doit être un nombre positif avec un point décimal (ex. 8.50) et au moins 0.01 €.
  • « Doublon dans le fichier » : Deux lignes visent le même produit avec le même seuil : n'en gardez qu'une.
  • « La grille a été modifiée depuis l'aperçu » : Quelqu'un a modifié la grille entre-temps : relancez la vérification pour repartir d'un plan à jour.
